Delete old screenshots on iPhone with a Shortcut

A Shortcut can remove screenshots by age instead of deleting all of them.

Checked 21 Nov 2026 · by Emil Svetlichnyy, developer of Swipeo

Short answerIn the Shortcuts app, build a shortcut that finds Photos where the media type is Screenshot and the date is older than your cut-off, then runs Delete Photos. Published versions also exclude recent screenshots, hidden photos and favorites.

Steps

  1. Open Shortcuts → + to create a new shortcut.
  2. Add the action Find Photos. Filter: Media Type is Screenshot, Date Taken is before your cut-off date.
  3. Optionally add filters to exclude Favorites.
  4. Add Delete Photos, run the shortcut and confirm.
  5. Empty Recently Deleted to free the space.

Action names can change between iOS versions. Test on a small date range first. The shortcut moves items to Recently Deleted, it does not bypass the 30-day window.

Doing this with Swipeo

Prefer to decide per screenshot rather than by date? Open the app, swipe or tap to keep or delete, and check Swipeo's trash before anything reaches the iPhone's Recently Deleted.

Download on theApp Store

Swipeo runs on iPhone and iPad, free to download with in-app purchases (what the app does). Items you delete go to Swipeo's own trash first; emptying it moves them to the iPhone's Recently Deleted, so iOS rules such as the 30-day window and iCloud sync still apply.

FAQ

Is a Shortcut better than Select All?

It is better if you want to keep recent screenshots. For a one-time wipe, the album's Select All is simpler.

Does it ask before deleting?

iOS shows a confirmation for Delete Photos. Read the count before you confirm.
