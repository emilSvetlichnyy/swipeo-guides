What does "Merge Duplicates" do on iPhone?

It keeps one copy and sends the others to Recently Deleted.

Checked 21 Nov 2026 · by Emil Svetlichnyy, developer of Swipeo

Short answerMerge in Photos → Utilities → Duplicates keeps one version of each set and moves the other copies to Recently Deleted. Storage only comes back after those copies are deleted there or after 30 days.

Steps

  1. Photos → Albums → Utilities → Duplicates.
  2. Review a set; tap Merge (or Select several sets → Merge).
  3. Confirm the number of copies to be merged.
  4. Then Recently Deleted → Select → Delete All, if you want the space now.

Because the discarded copies sit in Recently Deleted, you can still recover one within 30 days if Merge picked the wrong version.

FAQ

Is Merge safe?

It is reversible for 30 days through Recently Deleted. Check a few sets before merging everything.

Does Merge combine edits or metadata?

Apple describes it as keeping the best quality version; details of what is combined can vary by iOS version, so check Apple's current notes.
